# Zapocet2 — GIS projekt

Krátký projekt pro práci s vektorovými daty (GeoJSON / GPKG) a vizualizaci ve webovém náhledu.

Obsah projektu
- `geojson_obce.geojson` — hranice obcí v GeoJSON formátu
- `komunikace_mikeska.gpkg`, `komunikace.geojson` — komunikace/vektorová data
- `zapocet_projekt.qgz` — QGIS projekt
- `index.html` — jednoduchý webový náhled / viewer
- `zapocet2_styl.sld` — styl pro WMS/vektorové vrstvy

Jak začít
- Otevřít projekt ve QGIS: otevřít `zapocet_projekt.qgz` a načíst vrstvy.
- Pro rychlý náhled v prohlížeči: otevřít `index.html` (např. dvojklikem nebo přes `Live Server`).

Poznámky
- Datové soubory (shapefile, DBF, GPKG atd.) mohou být velké — v repozitáři sledujte jen to, co potřebujete.
